# HW10 - Find the Most Similar Keyword!
- Implement the Longest Common Subsequence (LCS) algorithm
- Add each keyword into an array
- Given a query string, find the keyword whose name is most similar to it

---
## Commands

### 1. add(Keyword k)
Insert a keyword `[name, count]` into an array.

**Format:**
```
add <name> <count>
```

**Example:**
```
add Fang 3
```

---

### 2. find(String s)
Find and print the keyword whose `name` has the longest common subsequence (LCS) with `s`, among all keywords added so far.
- Comparison is **case-sensitive**.
- `count` does not affect which keyword is selected — it is only used for the printed output.
- If multiple keywords tie for the longest LCS length, the keyword that was **added earliest** wins.

**Format:**
```
find <s>
```

**Example:**
```
find NTU
```

**Output:**
- If no keyword has been added yet:
  ```
  InvalidOperation
  ```
- Otherwise:
  ```
  NTU: [NCCU, 2]
  ```

---

## The LCS Algorithm

Implement the dynamic-programming algorithm introduced in Lecture 10 to compute the length of the longest common subsequence of two strings.

- The lecture defines the table using `L[-1][k] = 0` for an empty prefix, but Java arrays cannot use a `-1` index. Instead, build a table of size `(x.length()+1) x (y.length()+1)`, where `L[i][j]` is the LCS length of `x`'s first `i` characters and `y`'s first `j` characters. Row 0 and column 0 (empty prefixes) are then naturally all 0, and the final answer is `L[x.length()][y.length()]`.
- You only need the LCS **length**, not the actual common subsequence string.

## Input / Output Specification

**Input:**
- Each line of input contains one command.
- Tokens are separated by spaces.

**Output:**
- Separate the query string and the result with `: ` (colon, space).
- An unrecognized command (anything other than `add` or `find`) means the input does not match the expected format — the program must throw an exception instead of continuing to run.

## Example

**Input:**
```plaintext
add Fang 3
add Yu 5
add NCCU 2
add UCSB 1
add Management 4
add Information 5
find NTU
find Manager
```

**Output:**
```plaintext
NTU: [NCCU, 2]
Manager: [Management, 4]
```

**Tie-break example**

**Input:**
```plaintext
add Aa 1
add Ab 1
find A
```

**Output:**
```plaintext
A: [Aa, 1]
```
